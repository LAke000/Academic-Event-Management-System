1. SESSION STORAGE API (js/storage.js)
--------------------------------------------------------------------------------
- Added session storage key and default session constant:
    const AUTH_SESSION_KEY = "academic_auth_session";
    const DEFAULT_AUTH_SESSION = {
      authenticated: false,
      role: "guest",
      studentId: null,
      name: null,
    };

- Implemented static methods on StorageService:
    * StorageService.getAuthSession():
      Reads AUTH_SESSION_KEY defaulting strictly to DEFAULT_AUTH_SESSION:
      { authenticated: false, role: "guest", studentId: null, name: null }

    * StorageService.setAuthSession(session):
      Persists defensively normalized session:
      {
        authenticated: Boolean(session?.authenticated),
        role: session?.role || "guest",
        studentId: session?.studentId || null,
        name: session?.name || null
      }

    * StorageService.saveAuthSession(session):
      Alias for setAuthSession for full backwards-compatibility.

    * StorageService.clearAuthSession():
      Resets AUTH_SESSION_KEY to DEFAULT_AUTH_SESSION.

    * StorageService.clearAllData():
      Clears events, registrations, feedback, reminders, clears auth session,
      and resets active role to "guest" and student ID to "ALL".

    * StorageService.resetDatabase():
      Updated to purge AUTH_SESSION_KEY alongside all database tables and reseed.
